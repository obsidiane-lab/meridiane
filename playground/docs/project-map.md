# Carte du playground

- `README.md` : démarrage, commandes et validation manuelle.
- `core/` : Symfony/API Platform, entités Conversation/Message et publication Mercure.
- `webfront/src/app/` : shell Foundation, stores, repositories, services et pages de test.
- `webfront/src/app/shared/ui/` : primitives Spartan générées, gérées par son CLI.
- `webfront/bridge/` : modèles et runtime générés par la CLI locale Meridiane.
- `@obsidiane/` : runtime FrankenPHP, Caddy et configuration frontend.
- `Makefile`, `Dockerfile`, `compose.yaml` : commandes et environnement local.
- `.codex/`, `.agents/`, `AGENTS.md` : socle agentique conservé de Foundation.

Les sources du générateur Meridiane sont dans `../packages/meridiane/`, hors du playground.
