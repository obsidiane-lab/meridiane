# Capacités du playground

| Capacité | Validation |
| --- | --- |
| Conversation et Message | CRUD API Platform, modèles générés et relations par IRI. |
| Stores à signaux | Même ressource native alimentée par HTTP et Mercure. |
| Relations différées | Chargement individuel des messages et de leur conversation. |
| Temps réel | Création, modification et suppression depuis un second client. |
| Bridge local | Génération depuis le contrat backend avec les sources Meridiane du dépôt. |
| UI Foundation | Shell Angular et composants Spartan existants. |

Cette application de test n'inclut ni connexion OIDC ni ressource Project.
